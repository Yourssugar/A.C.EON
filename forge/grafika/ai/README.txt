Файлы для «Убрать фон» в графической мастерской FORGE. Всё работает в браузере посетителя, фото никуда не отправляется.

silueta.onnx
  Облегчённая модель U-2-Net (silueta, 43 МБ), лицензия Apache-2.0.
  Авторы U-2-Net: Xuebin Qin и др., https://github.com/xuebinqin/U-2-Net
  Файл ONNX взят из проекта rembg (MIT), https://github.com/danielgatis/rembg

ort.wasm.min.js, ort-wasm-simd-threaded.mjs, ort-wasm-simd-threaded.wasm
  ONNX Runtime Web 1.20.1, лицензия MIT, Microsoft, https://github.com/microsoft/onnxruntime

Старый файл u2netp.onnx больше не нужен, его можно удалить.
